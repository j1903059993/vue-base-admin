# Quick start

Install Node.js 20.19 or later and pnpm, then run:

```bash
pnpm install
pnpm dev
```

Copy `.env.example` to `.env.local` when you need local overrides. Use `admin / admin123` for the complete demonstration. Before publishing changes, run `pnpm lint`, `pnpm typecheck`, `pnpm test:run`, and `pnpm build`.
